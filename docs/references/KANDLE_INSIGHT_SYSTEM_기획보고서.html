2.1

KANDLE INSIGHT SYSTEM 개요

SERVICE DEFINITION

KANDLE INSIGHT SYSTEM은 관계사가 직접 조회할 수 없는 교보문고 데이터를 AI Agent가 분석하고,
분석 결과를 KANDLE 금융의 보안 기준에 맞는 Insight 형태로 제공하여 관계사의 고객 이해와 마케팅 활용을 지원하는 AI 기반 Insight 활용 체계입니다.

2.2

KANDLE INSIGHT SYSTEM 전체 구조

전체 구조는 좌측 KANDLE 금융(금융 폐쇄망) / 중앙 망연계·통제 구간 / 우측 KANDLE 문고의 3개 영역으로 구분됩니다.
KANDLE 금융에서는 질문이 나가고(② Question OUT), 보안 검증을 통과한 Insight만 들어옵니다(⑤ Approved Insight IN).
관계사에게 교보문고의 Raw Data나 Query 결과가 직접 전달되지 않습니다.
