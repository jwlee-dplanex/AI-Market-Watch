## 1. 배경 — 한 문단

AI Market Watch는 금융사와 보험사의 AI 도입 동향을 매일 수집해 정리하는 사내 리서치 도구예요. 지금은 로컬 PC에서만 돌고 있어서 사람이 켜 두지 않으면 수집이 멈춥니다. 이걸 샌드박스에 올려 상시 구동으로 바꾸려 합니다.

이용자는 사내 소수이고, 하루 한 번 기사를 모으는 배치가 전부예요. 데이터베이스 크기가 **22MB**라 일반적인 3-tier 구성(로드밸런서 + 오토스케일링 + 관리형 DB)이 요구하는 규모에 한참 못 미칩니다. 그래서 **EC2 한 대에 전부 올리는 최소 구성**으로 요청합니다.

| | |
|---|---|
| 리전 | 서울 (`ap-northeast-2`) |
| 구성 | EC2 1대 (웹 + DB 동시 구동) |
| 예상 비용 | EC2 인스턴스 요금 하나가 사실상 전부 |
| 이용자 | 사내 소수 |

### 2-3. 보안그룹 — 인바운드는 사내 IP만

- [ ] 요청함  [ ] 승인  [ ] 거절  [ ] 조건부

| 포트 | 용도 | 허용 대상 |
|---|---|---|
| 80 / 443 | 화면 접속 | 사내 공인 IP |
| 22 | SSH 접속 (배포와 점검) | 사내 공인 IP |

⚠️ **인터넷 전체 공개는 하지 않습니다.**

SSM Session Manager도 함께 켜 주시면 좋겠어요. 평소에는 SSH를 쓰고, **보안그룹을 잘못 건드려 접속이 막혔을 때 들어갈 경로**로만 씁니다. 추가 비용이 없습니다.

### 2-4. 🔴 아웃바운드 — 세 곳으로 나가야 합니다

- [ ] 요청함  [ ] 승인  [ ] 거절  [ ] 조건부

**이 문서에서 가장 중요한 항목이에요.** 보안 정책상 아웃바운드가 기본 차단인 경우가 많은데, 아래 세 곳이 막히면 각각 무엇이 죽는지가 다릅니다.

| 대상 | 용도 | 막히면 | 우회 |
|---|---|---|---|
| **네이버 뉴스 API** (`openapi.naver.com`) | 기사 수집 | 🔴 **시스템이 성립하지 않음** | **없음** |
| **AWS Bedrock Runtime** (`bedrock-runtime.ap-northeast-2.amazonaws.com`) | 기사 요약과 분류 (LLM) | LLM 기능 전부 중단 | VPC 엔드포인트 가능한지 확인 필요 |
| **GitHub** | 코드 배포 (`git pull`) | 배포 불가 | 로컬 빌드 후 SSH나 SSM으로 올리기 |

🔴 **Bedrock은 `Bedrock Runtime`만 씁니다. `Bedrock AgentCore`는 쓰지 않아요.** 이름이 비슷하지만 다른 서비스라 엔드포인트도 IAM 권한도 다릅니다.

| | 무엇 | 우리 |
|---|---|---|
| **Bedrock Runtime** | 모델에 프롬프트를 보내고 답을 받는 것 (`InvokeModel` / `Converse`) | ✅ 씁니다 |
| **Bedrock AgentCore** | 그 호출을 반복하며 도구를 부르고 기억을 유지하는 에이전트를 AWS가 대신 돌려주는 상위 계층 | ❌ 안 씁니다 |

우리 워크로드는 **버튼 한 번에 프롬프트 한 번, 결과 한 번**이라 에이전트 루프가 없어요. AgentCore가 대신 돌려줄 것이 없습니다. 비용 문제가 아니라 쓸 기능이 없어서예요.

⚠️ 엔드포인트 주소는 표준 형식을 적은 것이라 **devops와 함께 콘솔에서 확인**해 주세요. 그리고 **교차 리전 추론(cross-region inference)을 쓰면 다른 리전 엔드포인트로도 나갈 수 있어서** 그 경우 허용 대상이 늘어납니다 — 같은 샌드박스의 다른 프로덕트가 실제로 그렇게 쓰고 있으니 함께 확인이 필요합니다.

🔴 **네이버 API가 막히면 인스턴스를 받아도 쓸 수 없습니다.** 기사를 모으는 것이 이 도구의 첫 단계라, 여기가 막히면 나머지가 전부 무의미해져요. **다른 항목이 다 거절되더라도 이것 하나는 확인이 필요합니다.**

## 3. 요청하지 않는 것과 이유

미리 받아 두면 편할 것 같지만, **지금 안 쓰는 걸 요청하면 "왜 필요하냐"가 붙어 협의가 길어집니다.** 전부 나중에 추가하기 쉬운 항목이라 뺐어요.

| | 왜 지금은 안 받나 |
|---|---|
| RDS | 데이터 22MB. EC2 요금과 별개로 DB 요금이 또 붙는데 관리형 이점을 체감할 규모가 아님 |
| 로드밸런서 (ALB) | 붙일 인스턴스가 한 대뿐이라 시간당 고정요금이 그대로 낭비 |
| CloudFront | 정적 파일이 825KB. CDN이 이점을 낼 트래픽 규모가 아님 |
| WAF, Shield | 보안그룹으로 접근을 원천 차단하므로 막을 위협에 노출될 경로가 없음 |
| ECR, CI/CD 파이프라인 | EC2에서 직접 빌드하면 저장과 전송 비용이 안 붙음 |
| 도메인 (Route 53) | 후순위로 이미 결정됨. 지금은 고정 IP로 접속 |
| S3 | 백업을 하지 않기로 결정 |

## 5. 우리 쪽에서 이미 정한 것 — 참고용

devops가 물어볼 수 있는 항목들이에요.

| 질문 | 우리 답 |
|---|---|
| 인증은 어떻게 하나요 | 🔴 **애플리케이션 인증을 붙이지 않기로 했습니다.** 사내 IP 허용이 유일한 접근 제어예요. 정보보안 권고는 있었고, 그럼에도 이렇게 결정했습니다 |
| 백업은 어떻게 하나요 | **하지 않기로 했습니다.** 대신 인스턴스 종료 시 디스크가 삭제되지 않게 설정합니다 |
| 스케줄러가 도나요 | 안 돕니다. 사람이 화면에서 버튼을 눌러야 실행돼요 |
| LLM은 무엇을 쓰나요 | AWS Bedrock을 직접 호출합니다. Bedrock AgentCore는 쓰지 않아요 |
| 데이터가 밖으로 나가나요 | 네이버 API로 검색어가 나가고 기사가 들어옵니다. LLM은 Bedrock이라 AWS 안에서 끝나요 |
| 다른 시스템과 연계되나요 | 이번 범위에서는 없습니다 |
