{% comment %} 기간 선택 (2026-07 PM 정책 "대시보드·지식그래프 공통 기간 필터" — docs/planning.md 참고). 카드별 셀렉터가 아니라 "핵심 지표" 섹션 전체를 지배하는 셀렉터 하나 — 3개 카드가 모두 같은 period를 따른다. ⚠️ 2026-08-06 사용자 피드백으로 순수 GET 링크(전체 페이지 리로드) → HTMX 부분 갱신으로 전환했다. 이전 주석엔 "이 프로젝트에 아직 hx-get 기반 필터 갱신 패턴이 없고 … 새 인터랙션 패턴을 도입하는 비용이 크다고 판단했다"고 적혀 있었는데, 그 판단이 전제한 비용은 감수할 만하다는 쪽이었으나 실제로 청구된 비용(핵심 지표가 대시보드 최하단으로 이동한 뒤 필터 클릭마다 스크롤이 맨 위로 튕기는 것, 커밋 8ca6a33)이 그 판단을 뒤집었다 — "hx-get 패턴이 없다"는 이유는 이 커밋으로 해소됐고, 뉴스 목록(news/list.html)의 필터·페이지네이션이 여전히 순수 GET 링크인 것은 그쪽이 전체 페이지 이동이 자연스러운 목록 화면이라 그대로 둔다(불일치가 아니라 화면 성격이 다름). 각 버튼은 href(순수 GET, JS 비활성 시 폴백 겸 접근성)와 hx-get(fragment 경로, JS 활성 시 우선)을 모두 갖는다. hx-target="#dashboard-metrics" + hx-swap="outerHTML"로 이 div 전체를 교체하고 (버튼 자체가 응답에 포함되므로 다음 클릭도 계속 동작), hx-push-url로 주소창은 fragment 경로가 아니라 현재 페이지 기준 "?period=…"만 남긴다(새로고침·링크 공유 시 전체 페이지 뷰가 같은 period로 열려야 하므로). 기본값은 "전체"(services/periods.py DEFAULT_PERIOD)이며 뷰가 유효하지 않은 값은 그 기본값으로 취급한다(PE 스펙 참고). {% endcomment %}
